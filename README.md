
# FitLog - Workout Planner

FitLog is a simple workout planning website built with Next.js. Users can explore workouts, create daily plans, and save workouts for later.

# Technologies Used

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- Context API
- React Toastify

## 5 Key Features

1. View workouts with images and details.
2. Add workouts to Today's Plan.
3. Save workouts for later.
4. Mark workouts as completed and remove them.
5. Sort workouts by duration, calories, and rating.
